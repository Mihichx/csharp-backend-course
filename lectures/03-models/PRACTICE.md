# Практическое задание: «Создание API-контроллера с моделью и полным CRUD»

Задание: По аналогии с контроллером `StudentsController`, реализуйте новый изолированный контроллер для другого списка. Вам необходимо создать:

1. Модель данных в папке `Models`.
2. API-контроллер с поддержкой полного CRUD (Get со строкой поиска, GetById, Post, Put, Patch для одного любого свойства модели кроме Id, Delete).
3. Отдельный `.http` файл для тестирования всех 6 ручек.

Вы можете выбрать свою тему или взять один из предложенных вариантов:

## Вариант 1: 🎮 `GamesController` (маршрут: `api/games`)

_Описание:_ Бэклог видеоигр, которые студент планирует пройти во время каникул.

- `Id` (int) — Уникальный номер игры.
- `Title` (string) — Название игры.
- `Platform` (string) — Платформа (PC, PS5, Xbox, Switch).
- `HoursToBeat` (int) — Сколько часов займет прохождение.

## Вариант 2: 😂 `MemesController` (маршрут: `api/memes`)

_Описание:_ Коллекция мемов, которые студент сохраняет для разных жизненных ситуаций.

- `Id` (int) — Уникальный номер мема.
- `Title` (string) — Название мема (например, «Когда открыл IDE за 5 минут до дедлайна»).
- `Category` (string) — Категория (Учёба, Программирование, Экзамены, Жизнь).
- `FunnyLevel` (int) — Насколько мем смешной, от 1 до 10.

## Вариант 3: 🍕 `ShawarmaController` (маршрут: `api/shawarma`)

_Описание:_ Карта-рейтинг точек с шавермой вокруг колледжа для оценки студенческого обеда.

- `Id` (int) — Номер точки.
- `Address` (string) — Где находится (например, "У метро", "За углом общежития").
- `Price` (double) — Стоимость в рублях.
- `HasCheeseLavash` (bool) — Можно ли заказать сырный лаваш.

## Вариант 4: 🧙 `WizardsController` (маршрут: `api/wizards`)

_Описание:_ Каталог волшебников, которых можно было бы нанять для выполнения студенческих задач.

- `Id` (int) — Уникальный номер волшебника.
- `Name` (string) — Имя волшебника.
- `Spell` (string) — Основное заклинание.
- `Mana` (int) — Запас маны от 1 до 100.
